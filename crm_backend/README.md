# CRM Backend – Django + DRF + PostgreSQL

This is the backend of a CRM system built with **Django**, **Django REST Framework**, and **PostgreSQL**.

---

## 🚀 Features

- JWT-based Authentication
- Company & Employee Management
- RESTful API with DRF
- PostgreSQL Database
- Modular apps for clean structure
- Admin panel for quick control

---

## 🛠 Tech Stack

- Python 3.13
- Django 4.x+
- Django REST Framework
- PostgreSQL
- Pipenv for dependency management
